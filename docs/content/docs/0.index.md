description: 安装方式、token 契约，以及 paper、flat、term 三种风格。
kicker: 文档
---

库本身没有自己的样子。`core` 和 `vue` 只管行为和契约，样子在风格里。

- [安装](/docs/install)：git 依赖、Nuxt 的 `build.transpile`、本地还没推的改动怎么接到项目里。
- [Token](/docs/tokens)：十二个变量。每个风格都要定义，组件只读它们。
- [paper](/docs/paper)、[flat](/docs/flat)、[term](/docs/term)：同名组件，同一套 props，不同的表面。
