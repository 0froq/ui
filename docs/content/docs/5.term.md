反白表示当前项。给 `Choice` 传了 `prefix` 之后，下面的命令行把选择敲出来，敲完才改 `v-model`。没传 `prefix`，或者系统开了减弱动效，就立刻提交。

```ts
import '@froq/ui/term/style.css'
import { Choice, Toggle } from '@froq/ui/term'
```

页面或区块加上 `class="ui-term"`。

## Props

### Choice

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `v-model` | `string` | 当前值，必填。有 `prefix` 时，要等命令行敲完才变 |
| `options` | `{ value, label }[]` | 选项 |
| `label` | `string` | 可选。这组选择的名字，读屏用 |
| `prefix` | `string` | 可选，term 独有。命令行前缀，例如 `:set tone=` |

### Toggle

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `v-model` | `boolean` | 默认 `false` |
| `label` | `string` | 必填。读屏名称。没写 on/off 文案时也当作可见文字 |
| `on-label` | `string` | 可选。打开时的词 |
| `off-label` | `string` | 可选。关闭时的词 |
