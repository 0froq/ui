---
title: Token
description: 十二个变量。风格只换这些值，组件不认识别的颜色和字体。
kicker: 文档
---

每个风格在自己的作用域类上定义下面这些变量：`.ui-paper`、`.ui-flat`、`.ui-term`。

`--ui-bg` `--ui-fg` `--ui-muted` `--ui-faint` `--ui-line` `--ui-accent` `--ui-font-display` `--ui-font-text` `--ui-font-meta` `--ui-ease` `--ui-dur` `--ui-radius`

颜色用 `light-dark()`，跟随系统。在自己或祖先上写 `data-theme="light"` 或 `data-theme="dark"` 可以强制。页头的 light / dark 就是在改 `<html>` 的 `data-theme`，下面三块会一起变。

作用域是一个类，不是全局。一块区域写上 `class="ui-term"`，那一块就是终端，可以和别的风格放在同一页。

只想要 token、不用组件，单独引 `@froq/ui/<style>/tokens.css`。

`pnpm check:tokens` 会检查每个风格都定义了全部变量。
