来自 paper-landing。选中项旁边有一颗点；换选项时，点拉成线，再收回成点。减弱动效时不播放这段。

```ts
import '@froq/ui/paper/style.css'
import { Choice, ChoiceCircle, Toggle } from '@froq/ui/paper'
```

页面或区块加上 `class="ui-paper"`。

::demo{skin="paper" name="toggle"}
::

## Props

`Choice` 和 `ChoiceCircle` 的 props 相同。

### Choice

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `v-model` | `string` | 当前值，必填 |
| `options` | `{ value, label }[]` | 选项。`value` 是字符串 |
| `label` | `string` | 可选。这组选择的名字，读屏用 |

### Toggle

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `v-model` | `boolean` | 默认 `false` |
| `label` | `string` | 必填。开关的名字，读屏用，不显示 |
| `on-label` | `string` | 打开时的词，默认 `on` |
| `off-label` | `string` | 关闭时的词，默认 `off` |
